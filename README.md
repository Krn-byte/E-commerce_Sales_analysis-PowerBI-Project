# E-commerce Sales Analysis Dashboard | Power BI

## Project Overview

This project focuses on visualizing and analysing e-commerce sales data using Microsoft Power BI. The interactive report presents sales performance, order-related trends, sales targets, and geographical sales distribution through multiple dashboards and visualizations.

The objective is to transform sales data into meaningful visual insights that make it easier to explore business performance, compare results across categories and countries, and monitor sales-related metrics.

## Project Objectives

- Analyse sales performance using interactive dashboards.
- Explore order trends and sales-related metrics.
- Monitor sales targets and performance indicators.
- Visualize sales distribution across different countries.
- Present data through charts, tables, KPI visuals, and maps.
- Organize business data into a structured and easy-to-understand reporting interface.

## Tools and Technologies

- **Microsoft Power BI Desktop**

## Dashboard Pages

### 1. Sales Team

This page provides a sales-team-focused view of the report using multiple visualizations.

It includes:
- Column and clustered column charts
- Sales KPI card
- Combined line and column chart
- Tables for detailed information
- Bar charts for comparisons
- Interactive slicer for filtering data

### 2. Orders

This page focuses on visualizing order-related information and associated sales trends.

It includes:
- Line charts for trend analysis
- Geographical maps
- Tables for detailed data
- 100% stacked column chart
- Clustered column and bar charts
- Area chart for visualizing trends

### 3. Sales Target

This page provides a dedicated view for exploring sales targets and related performance indicators.

It includes:
- KPI visual
- Interactive slicers for filtering the report

### 4. Sales in Each Country

This page presents geographical sales information through a map visualization, allowing users to explore the country-wise distribution of sales.

### 5. SM Sales by Country

This page provides a tabular view of sales by country, supporting detailed inspection and comparison of the available data.

## Key Features

- Multiple report pages organized by business topic.
- Interactive filtering through slicers.
- Visual comparison of sales metrics.
- KPI-based reporting.
- Geographical sales visualization.
- Combination of charts, maps, and tables.
- Consolidated view of sales, orders, and target-related information.

## Analytical Approach

The project uses the following reporting approach:

1. **Data exploration:** Review the available sales and order-related data.
2. **Data visualization:** Represent information using appropriate charts, tables, KPI visuals, and maps.
3. **Performance monitoring:** Use KPI and target-focused visuals to present relevant performance measures.
4. **Geographical analysis:** Visualize country-wise sales distribution.
5. **Interactive reporting:** Use slicers and report filters to explore the data from different perspectives.

## How to Use

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open `E-commerce_Sales_Visualization.pbix` in Power BI Desktop.
4. Navigate through the report pages to explore the visualizations.
5. Use the available slicers and filters to interact with the report.

**Note:** Data refresh may require access to the original data source and appropriate connection settings.
